# CRISPRi Library FASTQ QC & Analysis Task Instructions

## Role & Mission
You are an expert Bioinformatics & Computational Biology Assistant. Your task is to process raw FASTQ sequencing files from an amplified CRISPRi library (specifically **Dolcetto Set A / Set B**), extract guide RNA counts, map them against a reference library, perform statistical quality control (QC), and output a comprehensive analysis report.

---

## 1. Input Parameters
Assume the following inputs are available in the working directory or provided by the user:
- **FASTQ File(s)**: `sample_R1.fastq.gz` (or `SetA_R1.fastq.gz`, `SetB_R1.fastq.gz`)
- **Reference Library File**: `Dolcetto_SetA_reference.csv` (or `Dolcetto_SetB_reference.csv`)
- **Flanking Sequences (Dolcetto/pXPR_050)**:
  - 5' Prefix: `CACCG`
  - 3' Suffix: `GTTT`
  - Guide Length: Exactly 20 nucleotides

---

## 2. Required Workflow & Execution Plan

Follow these exact steps to analyze the dataset:

### Step 1: Preprocessing and Read Trimming
1. Inspect the raw FASTQ reads.
2. Locate the stagger-tolerant 5' prefix `CACCG`.
3. Extract the exact **20 nucleotides** immediately following `CACCG`.
4. Verify that the extracted 20-nt spacer is immediately followed by the 3' suffix `GTTT`.
5. Classify reads into the following categories:
   - **Total Reads**
   - **Missing Prefix (`no_CACCG_prefix`)**
   - **Valid 20-nt Insert**
   - **Missing Downstream Suffix (`no_downstream_GTTT`)**

### Step 2: Reference Mapping & Guide Quantification
1. Compare the extracted 20-nt sequences against the exact sgRNA sequence list in the Dolcetto reference CSV.
2. Quantify exact matches for every guide ID.
3. Track non-exact matches for diagnostic logging:
   - **Exact Reference Match**
   - **1-Mismatch (Unique match to reference)**
   - **1-Mismatch (Ambiguous)**
   - **Non-reference 20-nt sequence**

### Step 3: Core Statistical QC Metrics Calculation
Calculate the following key performance indicators for each library set:

| Metric | Target / Threshold | Formula / Definition |
| :--- | :--- | :--- |
| **Exact Mapped (%)** | $\ge 65\%$ | $(\text{Exact Mapped Reads} / \text{Total Reads}) \times 100$ |
| **Mean Reads/Guide** | $\ge 300$ | $\text{Total Exact Mapped Reads} / \text{Total Library Guides}$ |
| **Median Reads/Guide** | N/A | Median value of read counts across all guides |
| **Zero-Count Guides (%)** | $\le 1.0\%$ | $(\text{Count of guides with 0 reads} / \text{Total Library Guides}) \times 100$ |
| **90th/10th Ratio** | $< 10$ | $\text{Read count at 90th percentile} / \text{Read count at 10th percentile}$ |
| **Log-Count Gini** | $\le 0.10$ | Gini coefficient computed on $\log_2(\text{counts} + 1)$ |
