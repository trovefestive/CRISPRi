Interpretation notes

  • Set A and Set B are assessed independently because they contain distinct guide sequences.
  • R2 is backbone-dominated and is not used for guide counting.
  • The local reference files contain 496 rows annotated NO-TARGET in each set; this is retained without modification.
  • Low exact mapping can reflect sequencing substitutions, oligo synthesis errors, cloning variants, or malformed inserts. The diagnostic one-mismatch categories help distinguish these possibilities.

Methods and references

The workflow streams compressed FASTQ records in chunks, locates the stagger-tolerant CACCG prefix, extracts the following 20 nucleotides, requires the downstream GTTT sequence, and matches exactly against the corresponding Dolcetto reference.

  • Addgene Dolcetto library specification
  • Broad GPP sgRNA sequencing protocol
  • MAGeCK-VISPR QC framework

Output files

Guide-level and gene-level counts are in tables/. Read-structure and mismatch diagnostics are in diagnostics/. PNG and vector PDF figures are in figures/.
